# CommunityServe - Server

Backend API for the CommunityServe social development events platform.

## GitHub Repository

[https://github.com/sojib-fullstack-dev/CommunityServe-Server](https://github.com/sojib-fullstack-dev/CommunityServe-Server)

## Features

- RESTful API using Express.js.
- MongoDB database integration.
- User authentication and JWT verification.
- Create and retrieve community events.
- Update and delete events.
- Join and manage joined events.
- Protected API routes and authorization.

## Technology Stack

- Node.js
- Express.js
- MongoDB
- Better Auth
- JWT
- JavaScript

## Installation

```bash
git clone https://github.com/sojib-fullstack-dev/CommunityServe-Server.git

cd CommunityServe-Server

npm install

npm run dev
```

## Environment Variables

Configure your `.env` file with the required MongoDB URI, authentication secrets, and other environment variables.
